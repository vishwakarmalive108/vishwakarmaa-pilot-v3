# V33 Employee Master Profile

The employee record is now a unified workforce identity.

## Profile layers
- Personal details
- Contact/address
- Photo
- Blood group
- Emergency contact
- Current employment
- Employment history
- Documents and verification status
- Face identity
- Fingerprint identity
- NOC history
- Red Flag history
- Activity/audit timeline

## Privacy-by-design
Sensitive values are masked in normal UI. Access should be role-based, and identity/document data should never be exposed in association-wide notifications by default.

## Employment history
Historical employment is informational unless verified. Only an active registered permanent employment record participates in the cross-mill gate rule.

## Next integration
This profile becomes the single identity record used by attendance, daily labour, payroll, biometric devices, NOC and Red Flag modules.
