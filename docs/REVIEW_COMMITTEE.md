# V29 Review Committee

## Purpose
A special committee linked to the local Millers Association acts as a controlled review and escalation layer.

## Automatic workflow
Employer creates Red Flag
→ server authorization
→ committee case created
→ association update generated
→ committee review
→ resolution
→ audit trail.

## Association update policy
System-generated updates should contain the minimum necessary information. By default they should identify the case and severity without broadcasting sensitive employee details.

## Suggested statuses
QUEUED → UNDER_REVIEW → CLEARED / CONFIRMED / DISPUTED → CLOSED.

## Important governance rule
The system must not operate as an unverified public blacklist. Serious allegations should remain evidence-linked and reviewable, with a mechanism to correct erroneous reports and preserve an audit history.
