# V31 Miller Dashboard

The dashboard is the factory owner's command center.

## First-screen priorities
1. Today's total workforce.
2. Permanent vs daily labour.
3. Attendance health.
4. Employer-only Red Flags.
5. Gate decision flow.
6. Live attendance.
7. Payroll snapshot.
8. Association/Review Committee connection.

## UX principle
The owner should understand the factory's workforce situation within 10 seconds without opening multiple modules.

## Navigation
Overview / Permanent Employees / Daily-Fatak Labour / Attendance / Payroll / Documents / Red Flags / NOC Management / Review Committee / Settings.

## Important visibility rule
Red Flags are employer-controlled and sensitive. The dashboard does not expose committee-only or association-wide sensitive information beyond the permitted summary.
