# V54 — Association Command Centre

Adds the association governance layer: registered mill membership, Special Review Committee, system-generated updates from red-flag cases, association notices, network metrics, and controlled governance access.

## APIs
GET `/api/association/command-centre`
POST `/api/association/register`
POST/GET `/api/association/committee`
POST/GET `/api/association/notices`
POST `/api/association/sync`

The system detects and routes cases automatically; final penalty/enforcement decisions remain with the association committee.
