# V37 Association + Special Review Committee

## Purpose
Connect registered mills to an association governance layer without exposing unnecessary employee information.

## Components
- Association membership per factory
- Special Review Committee
- Review cases
- Case priority/status
- Assignment to committee members
- System-generated association updates
- Association notice board
- Aggregate compliance feed

## Red Flag relationship
An employer Red Flag can become a review case. The Red Flag itself is an operational alert; committee review provides a governance process and does not automatically establish misconduct.

## Visibility
Factory users retain employee-level access according to role. Association users receive case and aggregate information needed for policy oversight. Sensitive identity fields remain restricted.

## Future integration
- Committee voting/resolution workflow
- Notifications
- Meeting agenda/minutes
- Association-wide aggregate dashboards
- Formal policy/penalty workflow configured by the association
