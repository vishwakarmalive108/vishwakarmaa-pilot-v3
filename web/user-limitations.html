How limitations work
ROLEPERMISSIONUSER OVERRIDELIMITAUDIT

A user receives the permissions of their role. The Owner can then restrict or grant an individual permission and set operational limits for that specific sub-user. Sensitive actions create a security audit event.

IMPORTANT

The Red Flag remains an employer-facing security function. Sub-users only see it if their assigned permission allows it; resolving/managing Red Flags is separately permissioned.

V43 SECURITY PRINCIPLE

No sub-user should automatically inherit Owner authority. Access is explicit, granular and revocable. This structure also leaves room for future limits such as maximum advance amount, maximum attendance edits, module-level visibility, and approval thresholds.
